Glossaire TVA rapide
HT= Hors Taxe (sans TVA). Dans ce module, les montants à saisir sont en CHF HT.
TTC= Toutes Taxes Comprises. Prix affiché au client final.
Contre-prestation= ce que l’entreprise reçoit en échange de sa prestation.
IP= Impôt préalable, c’est-à-dire TVA payée sur les achats professionnels.
N° TVA= CHE-xxx.xxx.xxx MWST/TVA — à vérifier sur uid.admin.ch.
Méthode effective= TVA collectée sur ventes − impôt préalable réel sur achats.
TDFN / TaF= méthodes simplifiées séparées, non travaillées dans le module débutant.

Limites pédagogiques et dépôt officiel AFC
Note pédagogique importante: ce simulateur utilise un décompte TVA pédagogique inspiré du formulaire AFC pour l’apprentissage. Le vrai dépôt doit toujours être effectué dans l’ePortal AFC selon le formulaire et les instructions AFC en vigueur. Les cas ne remplacent pas une analyse TVA complète, notamment pour les prestations transfrontalières, les exclusions, les subventions et les corrections d’impôt préalable.
